# Vocabulaire coranique — niveau 8

Application de révision du vocabulaire des 7 fiches du niveau 8 (38 mots, 56 cartes), à installer sur iPhone ou tablette comme une appli.

**Ouvrir l'appli :** https://merouane7824-lgtm.github.io/Arabe_coran_niveau_8/

## Modes d'étude
- **Cartes** : retourner, glisser à droite (je sais) ou à gauche (à revoir), annuler.
- **Apprendre** : parcours guidé en manches de 7 cartes, chaque mot réussi dans les deux sens (écriture en option).
- **Test** : QCM noté, arabe → français, français → arabe ou mélangé.
- **Association** : relier les paires au chrono.
- **Éclair** : vrai ou faux en 60 secondes, avec combos.
- **Écrire** : taper le mot en arabe (voyelles facultatives).

Révision du jour par répétition espacée, paquets par fiche, favoris et erreurs, liste complète avec recherche, mode clair / nuit.

## Installer sur l'écran d'accueil
iPhone / iPad : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».
L'appli fonctionne ensuite hors connexion. La progression est enregistrée sur chaque appareil.

## Fichiers
- `index.html` : l'application complète (un seul fichier)
- `icons/` : icône (étoile du Rub el-Hizb, lettre ق, ٨ pour le niveau 8)
- `manifest.webmanifest`, `sw.js` : installation et fonctionnement hors ligne
